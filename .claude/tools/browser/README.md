# أدوات التصفح

أداتان تتيحان فتح صفحات الويب في متصفح Chromium حقيقي واستخراج بياناتها،
من داخل بيئة تشغيل الوكيل السحابية.

## لماذا نحتاجها

بيئة التشغيل السحابية تمنع Chromium من فتح أنفاق HTTPS مباشرة — كل محاولة
ترجع `ERR_CONNECTION_RESET`، وقد جُرّبت ستة إعدادات TLS مختلفة دون جدوى.
في المقابل يمر Node عبر بروكسي الوكيل بشكل طبيعي.

الحل: خادم محلي يجلب الصفحة عبر HTTPS من جهة Node، ثم يقدّمها للمتصفح
على `http://127.0.0.1`. وحتى لا تظهر الصفحة كنص خام، تُعاد كتابة روابط
الموارد (CSS، صور، خطوط) لتمر عبر الخادم نفسه، فتُعرض الصفحة بتنسيقها
الحقيقي.

## الاستخدام

```bash
cd .claude/tools/browser

# فتح صفحة: يطبع النص ويحفظ لقطة شاشة
node browse.js https://example.com

# لقطة بمسار محدد، وللصفحة كاملة
node browse.js https://example.com --shot out.png --full

# انتظار عنصر قبل القراءة، وإخراج JSON
node browse.js https://example.com --wait "h1" --json
```

`browse.js` يشغّل `relay.js` تلقائياً عند الحاجة، فلا داعي لتشغيله يدوياً.

### خيارات `browse.js`

| الخيار | الوظيفة |
|---|---|
| `--shot <path>` | مسار لقطة الشاشة (افتراضي `.cache/last-shot.png`) |
| `--full` | لقطة للصفحة كاملة لا للجزء الظاهر فقط |
| `--wait <selector>` | انتظار ظهور عنصر قبل قراءة المحتوى |
| `--timeout <ms>` | مهلة التحميل (افتراضي 60000) |
| `--limit <n>` | حد أحرف النص المطبوع (افتراضي 4000، و`0` = بلا حد) |
| `--json` | إخراج JSON بدل نص مقروء |
| `--no-shot` | تعطيل لقطة الشاشة |
| `--port <n>` | منفذ الوسيط (افتراضي 8899) |

### تشغيل الوسيط يدوياً

```bash
node relay.js --port 8899 --verbose     # تشغيل
curl http://127.0.0.1:8899/__relay/health   # فحص
```

## المتطلبات

- Node.js 18 أو أحدث
- حزمة `playwright` — مثبتة عالمياً في بيئة الوكيل. للتثبيت في بيئة أخرى:
  `npm install -g playwright`
- متصفح Chromium — مثبت مسبقاً عبر `PLAYWRIGHT_BROWSERS_PATH`. لا تشغّل
  `playwright install` داخل بيئة الوكيل.

## الحدود

- **JavaScript لا يُنفَّذ لجلب بيانات جديدة.** المتصفح ينفّذ الجافاسكربت
  الموجود في الصفحة، لكن أي طلب `fetch`/`XHR` يطلقه إلى نطاق خارجي سيفشل
  لأنه لا يمر عبر الوسيط. المواقع التي تبني محتواها بالكامل بعد التحميل
  تظهر ناقصة.
- **لا تسجيل دخول.** الصفحات المحمية بحساب لا تعمل — لا كوكيز ولا جلسات.
- **الروابط داخل الصفحة قابلة للنقر** لأنها أُعيدت كتابتها، لكن إرسال
  النماذج (POST) غير مدعوم؛ الوسيط يجلب بطلبات GET فقط.
- **`http://` تُرفع إلى `https://`** لأن بروكسي الوكيل لا يقبل إلا أنفاق
  HTTPS.
- **الملفات المؤقتة** في `.cache/` (لقطات وسجلات) مستثناة من Git.

## البدائل الأبسط

هذه الأدوات لازمة فقط عند الحاجة إلى **عرض** الصفحة أو التقاط صورتها.
للاطلاع على المحتوى نصياً فقط، أدوات الوكيل المدمجة أسرع وأوثق:
`WebSearch` للبحث و`WebFetch` لقراءة صفحة بعينها.
