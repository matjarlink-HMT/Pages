# مصادر التحقق — Source Harvesting

أدوات جلب مخططات السمات الحقيقية من المتاجر، والبيانات الخام التي بُنيت عليها
تعديلات `lib_*.py`. تاريخ الحصاد: **2026-08-10**.

## لماذا هذا المجلد

الجلسة الأولى بنت قوائم الخيارات من نتائج بحث مختصرة لأن الشبكة كانت محجوبة.
هذه الأدوات تستبدل ذلك بمصادر حيّة يمكن إعادة تشغيلها والتحقق منها.

## الملفات

| الملف | الوظيفة |
|---|---|
| `extract.py` | يستخرج مصفوفة `classifications` المضمّنة في صفحات منتجات إكسترا (موازنة أقواس، لا اعتماد على Regex هش) |
| `harvest.py` | يعيّن مسارات فئات إكسترا إلى عائلاتنا، يعيّن عيّنة من خريطة الموقع، ويجمّع أسماء السمات وقيمها المرصودة |
| `ounass.py` | يحلّل فلاتر أوناس المعروضة في HTML مباشرة (`<section class="Facet">`) |
| `diff_fam.py` | يقارن المحصود بالكتل الحالية في `lib_*.py` ويطبع الناقص |
| `extra_schemas.json` | الناتج الخام من إكسترا — 13 عائلة، مع عدد المنتجات المعاينة لكل تصنيف |
| `ounass_facets.json` | الناتج الخام من أوناس — الأزياء والأحذية والحقائب والمجوهرات |

## إعادة التشغيل

```bash
cd tools/product-properties/sources

# 1) اجمع روابط المنتجات من خرائط موقع إكسترا (51 شريحة، ~45,700 رابط)
curl -s https://www.extra.com/en-sa/sitemap.xml \
  | grep -oE '<loc>[^<]+Product[^<]+' | sed 's/<loc>//' > shards.txt
while read -r s; do curl -s "$s" | grep -oE '<loc>[^<]+' | sed 's/<loc>//'; done \
  < shards.txt > allurls.txt

# 2) احصد المخططات (العدد = منتجات لكل فئة)
python3 harvest.py 14

# 3) قارن بالكتل الحالية
python3 diff_fam.py mobile_phone laptop fridge
```

`harvest.py` يضع مهلة 0.4 ثانية بين الطلبات ويعيد المحاولة ثلاث مرات بتراجع أسّي.

## حالة الوصول للشبكة وقت الحصاد

| النطاق | الحالة | ما أُخذ منه |
|---|---|---|
| `gsmarena.com` | ✅ | تعداد فلاتر البحث المتقدم + ورقة مواصفات Galaxy S25 Ultra كاملة |
| `extra.com` | ✅ | مخططات `classifications` لـ13 عائلة + شجرة الفئات |
| `ounass.ae` | ✅ | فلاتر الأزياء والأحذية والحقائب والمجوهرات |
| `amazon.ae` | ✅ | متاح (لم يُستخدم — إكسترا غطّى نفس الفئات ببنية أوضح) |
| `sharafdg.com` | ⚠️ 403 | حماية ضد البوتات |
| `noon.com` | ❌ | محجوب على مستوى الشبكة |
| `namshi.com` | ❌ | محجوب على مستوى الشبكة |

نون ونمشي هما مصدرا الأزياء والتجميل الأساسيان في خطة التسليم الأصلية؛ أوناس
غطّى الأزياء والأحذية، لكن فلاتر التجميل فيه ضحلة (تصنيفات فقط، بلا درجات لون أو
تغطية أو لمسة نهائية). تحقّق `makeup` و `perfume` ما زال مفتوحاً.

## ملاحظة على البنية

مخطط سمات إكسترا يأتي **لكل تصنيف داخلي** لا لكل فئة معروضة — مثلاً الثلاجات
تنقسم إلى `LARGE`, `MEDIUM`, `SMALL`, `COMPACT`, `SIDE BY SIDE REFRIGERATOR`،
والغسالات إلى `AUTO FL`, `AUTO FE`, `TWIN TUB WASHER`, `WASHER&DRYER`.
`diff_fam.py` يدمج تصنيفات العائلة الواحدة قبل المقارنة.

القيم المرصودة هي ما ورد فعلاً في المنتجات المعاينة، وليست القائمة الكاملة
المسموح بها لدى المتجر؛ وسّعنا الشرائح حيث كان المدى واضحاً (مثل ضمان الضاغط
5/7/10 سنوات) وأبقينا القيم كما رُصدت حيث لم يكن كذلك.
