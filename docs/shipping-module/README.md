# وحدة إدارة الشحن — متجرلينك (MatjarLink Shipping Module)

حزمة التصميم الهندسي الكاملة لوحدة الشحن المدمجة داخل منصة متجرلينك.

> **الحالة:** التصميم معتمد، والتنفيذ الفعلي بمكدس متجرلينك (Laravel + MySQL) قائم في [`matjarlink-shipping/`](../../matjarlink-shipping/README.md) — المرحلتان ٠ و١ من خارطة التنفيذ.
> يرافق ذلك **نموذج تفاعلي مستقل** (`shipping-prototype/`) يبقى مرجعاً بصرياً لتجربة المستخدم.

---

## القرارات المعمارية المعتمدة

| القرار | الاختيار | السبب المختصر |
|---|---|---|
| المكدس التقني | Laravel 11 + MySQL 8 | مكدس منصة متجرلينك الحالي؛ Queues/Events/Scheduler جاهزة لعمليات التتبع والWebhooks |
| نمط الوحدة | Modular Monolith — `app/Domains/Shipping` | عزل كامل للنطاق مع بقاء المعاملات (Transactions) والصلاحيات وقاعدة البيانات مشتركة مع المنصة |
| تكامل شركات الشحن | Driver/Adapter Contract + Registry | إضافة أي شركة جديدة = ملف واحد + سطر تسجيل، بدون لمس النواة |
| الشركات بدون API | Manual Driver + Rate Card Engine | التاجر يدير المندوبين وشركات التوصيل الصغيرة داخل نفس الشاشات |
| تحديث الحالات | Webhook أولاً، Polling تكيّفي احتياطاً | تقليل استهلاك الـ API مع ضمان عدم فقدان أي حدث |
| الواجهة | نفس Design System للمنصة — Blade + Alpine في التنفيذ الحالي (Livewire اختياري للشاشات التفاعلية لاحقاً) | تشعر أنها جزء أصيل من متجرلينك لا نظام منفصل |
| العزل | Tenant Global Scope على `store_id` في كل جدول | أمان متعدد المستأجرين بشكل افتراضي لا اختياري |

## التنفيذ الفعلي (Laravel)

[`matjarlink-shipping/`](../../matjarlink-shipping/README.md) — حزمة قابلة للنسخ المباشر إلى تطبيق متجرلينك، بمسارات مطابقة لشجرة Laravel:

- ١٠ هجرات تُنشئ ١٧ جدولاً بالفهارس والقيود الفريدة
- عقد `CarrierDriver` + `CarrierRegistry` + `ManualDriver` عامل بالكامل
- آلة الحالات و`ShipmentEventRecorder` (الكاتب الوحيد لحالة الشحنة)
- خدمات الإنشاء والتسعير والمقارنة والبوالص والتحليلات
- ٤ متحكّمات و١٢ قالب Blade وورقة أنماط تشتق من نظام تصميم المنصة
- ٢٠ صلاحية و٥ أدوار و`TenantScope` عام
- اختبارات، منها اختبار عزل مستأجرين إلزامي

## النموذج التفاعلي

[`shipping-prototype/`](../../shipping-prototype/README.md) — صفحة مستقلة قائمة بذاتها، تُفتح مباشرة في المتصفح بلا خادم ولا اعتماد على أي منصة أخرى. تعرض:

- لوحة تحكم بمؤشرات حيّة ورسوم بيانية
- جدول الشحنات مع بحث وفلترة وفرز وتصدير
- صفحة تفاصيل الشحنة بالسجل الزمني الكامل
- معالج إنشاء شحنة من ٣ خطوات مع مقارنة أسعار حيّة
- إدارة شركات الشحن واختبار الاتصال
- تقارير ومقارنة أداء شركات الشحن

النموذج يعمل ببيانات مولّدة داخل المتصفح — غرضه **اعتماد التجربة والتصميم**، وليس تنفيذ المنطق الحقيقي.
