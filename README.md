# HMT OS — منصة إبراهيم الشخصية

منصة ويب متكاملة تعمل كمحرك للقرارات والسلوكيات اليومية.

## الأقسام
- **الرئيسية** (`index.html`) — لوحة قيادة: مهام اليوم، التقدم نحو أهداف الـ12 أسبوع، المواعيد القادمة.
- **الصحة** (`health.html`) — التقرير الصحي الكامل، المخطط اليومي، خطط التمارين A/B مع شرح الأداء، المكملات، المتابعة الأسبوعية والشهرية مع رسوم بيانية، والمستشار الصحي الذكي.
- **المالية** (`finance.html`) — الميزانية، المصاريف، الديون مع محاكي خطط السداد (Avalanche/Snowball)، والمستشار المالي الذكي.
- **متجرلينك** (`matjarlink.html`) — مؤشرات المشروع، الأفكار، رابط خطة التنفيذ (`HMT_Tasks.html`)، ومستشار الأعمال.
- **الوكيل الصوتي** (`voice-agent.html`) — دراسة إطلاق خدمة وكيل صوتي بالذكاء الاصطناعي لتجار متجرلينك: مسارات التنفيذ، المعمارية التقنية، حاسبة هوامش الربح، خطة ٩٠ يوم، والمخاطر.
- **النموذج التجريبي** (`voice-agent-demo.html`) — صفحة تُعرض على التاجر: عرض تسويقي + محاكاة مكالمة تفاعلية + لوحة تاجر + نموذج تسجيل اهتمام. صفحة مستقلة بتنسيقها الخاص (لا تعتمد على `assets/`). لعرض التسجيلات وتصديرها CSV افتحها بـ`?admin=1`، ولتفعيل إرسال الطلبات على واتساب اضبط `CONFIG.whatsapp` أعلى السكربت.
- **الإعدادات** (`settings.html`) — مفتاح Claude API، تصدير/استعادة نسخة احتياطية.

## المستشارون الأذكياء
ثلاثة مستشارين يعملون بنموذج Claude Opus مباشرة من المتصفح، كل واحد يقرأ البيانات الحية المسجلة في المنصة. التفعيل يتطلب مفتاح API من [platform.claude.com](https://platform.claude.com/) يُدخل مرة واحدة في الإعدادات (يُحفظ في جهازك فقط).

## التخزين
البيانات تُحفظ في متصفح الجهاز (localStorage). للاستخدام من أكثر من جهاز: صدّر نسخة احتياطية من الإعدادات واستوردها في الجهاز الآخر.

## التشغيل
الموقع ثابت بالكامل — يعمل عبر GitHub Pages بدون أي خادم:
Settings → Pages → Deploy from branch → `main` → `/ (root)`
